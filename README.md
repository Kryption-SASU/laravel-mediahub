# Contributor agreement signatures

This branch exists so that the signature file has somewhere to live.

⚠️ It is deliberately left unprotected. The automation that records a signature commits it
itself, and the default branch accepts no direct write — so the file cannot live there. Adding a
protection here would break the agreement flow for every first-time contributor, and the failure
would look like the automation being broken rather than a rule being enforced.

Nothing else belongs on this branch. The agreement itself is in `CLA.md`, on the default branch.
